# Service B — Prompt & AI Intelligence

Сервис «скрытой инженерии»: реестр стилей + улучшение пользовательского текста через LLM (OpenAI) + генерация профессионального текста для модели изображений.

## Proxy

Опционально: `PROMPT_SERVICE_OPENAI_PROXY_URL` — HTTP(S) proxy для запросов к OpenAI (пример: `http://user:pass@host:port`).
