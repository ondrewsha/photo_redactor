# Service B — Prompt & AI Intelligence

Сервис «скрытой инженерии»: реестр стилей (hidden templates) + режимы `enhance/creative` через GPT-5-mini (SDK `openai`) + сборка итогового промпта.

## Proxy

Опционально: `PROMPT_SERVICE_OPENAI_PROXY_URL` — HTTP(S) proxy для запросов к OpenAI (пример: `http://user:pass@host:port`).
